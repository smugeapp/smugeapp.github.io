# Smudge

Smudge is a painting studio for kids: brushes, movable stickers, colouring outlines (pictures, A–Z, 0–9), word art, backgrounds, frames, scenes and replay.

**Play it:** https://smugeapp.github.io/

It's an installable web app. On Android or a computer, tap **Install app**. On iPhone or iPad, tap **Share → Add to Home Screen**. It works offline after the first visit.
